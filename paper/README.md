# paper/

**This directory is the canonical Paper 1 manuscript.** If any other
`PAPER1_FREEFREE_*` copy in the broader working tree disagrees with the
files here, these win. The working-tree pointer map
(`Project Knowledge/CURRENT_PAPER.md`) is not shipped in this snapshot.

- `PAPER1_FREEFREE_DRAFT.tex` — LaTeX source (draft; standard `article`
  class, `amsmath`/`amssymb`/`booktabs`/`graphicx`/`tikz`/`hyperref`, no custom
  class file needed).
- `PAPER1_FREEFREE_SUPPLEMENTARY.tex` — JSV Supplementary Material (Frobenius
  construction, free-edge functional / surface-term algebra including the
  former main-text appendix, extra validation tables). Compile separately;
  the main text points at it as “Supplementary Material, §S.n”. There is
  no remaining main-text appendix.
- `PAPER1_FREEFREE_DRAFT.pdf` — compiled main-text PDF (no line numbers).
  Recompile after any `.tex` edit.
- `PAPER1_FREEFREE_SUPPLEMENTARY.pdf` — compiled Supplementary Material
  (Tables S.1–S.8). After a Supplementary `.tex` edit, recompile this
  PDF too — it is a separate document.
- `GRAPHICAL_ABSTRACT.pdf` / `.png` — JSV graphical abstract (standalone;
  not embedded in the manuscript). Regenerated by
  `scripts/make_graphical_abstract.py`.
- `HIGHLIGHTS.txt` — 5 Elsevier highlights, each ≤85 characters.
- `COVER_LETTER.md` — one-page JSV cover-letter draft. The GitHub/Zenodo
  DOI is stated as “at submission,” matching the Data and code availability
  section; fill the URL when the archive is minted.
- `FFFF_VARIATIONAL_DERIVATION.md` — repository companion: the full
  line-by-line derivation of the free-free variational functional (the
  Supplementary Material §S.2 condenses this).
- `paper_figures/` — embedded figures. The $\sigma_{\min}$ trace ships as
  both PNG and PDF (vector). Each of the four mode-shape panels now has a
  full-size PDF sibling (title + margin). Figure 2 still includes the
  `*_tight.png` crops so the four-up layout is not double-titled. Do not
  add `*_tight.pdf` copies of the titled files — pdflatex would pick them
  over the crops.

To recompile the manuscript: `pdflatex PAPER1_FREEFREE_DRAFT.tex` (run
twice for cross-references), from inside this directory so the relative
`\graphicspath{{paper_figures/}{./}}` resolves correctly. Compile
`PAPER1_FREEFREE_SUPPLEMENTARY.tex` the same way, as a second PDF. No
external `.bib` file — the bibliography is a `thebibliography` environment
inline in each `.tex` source.

The `.aux` / `.log` / `.out` files in this directory are pdflatex debris
and may lag the current `.tex`; ignore them. After a local two-pass
recompile they will match again.

This is a draft manuscript, not a final published version — see the title
page's date line and the top-level README's Status section for what is and
isn't closed.
