    13  !  OOP-vs-IP sanity check) for that specific mode, on a dense text grid a

    22  !  then 96, NMODES=60). This deck does NOT re-derive which mode number is   
    23  !  the target -- it LOCATES it dynamically each pass by computing   
    24  !  Omega_lit=2*pi*f*KLIT for every candidate mode (7..NMODES, skipping the  
    25  !  6 rigid-body modes) and keeping the closest to the target, exactly the   
    26  !  same free-search discipline the rest of this project uses (no

    30  !  every known IP mode of this geometry (lowest IP mode: 161.4 Hz, per  
    31  !  ansys_ff_oop_ext.inp's own header comment) -- no in-plane mode could be  
    32  !  mistaken for the target by frequency proximity. As a SECOND, independent 
    33  !  check (not just trusting that frequency gap), this deck also computes
    34  !  each selected mode's UZ-dominance and prints it for manual confirmation  
    35  !  before the eigenvector is trusted -- as an energy fraction UzFrac =  
    36  !  SUM(UZ^2)/SUM(UX^2+UY^2+UZ^2) via *VOPER(MULT)+*VSCFUN(SUM), the exact
