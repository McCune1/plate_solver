# ansys/

ANSYS Mechanical APDL decks and their text results, used as independent
finite-element validation targets throughout the paper. Binary ANSYS
scratch/result files (`file.db`/`.full`/`.rst`/`.esav`/etc.) are excluded —
they require a licensed ANSYS install to read and are regenerated by
rerunning the corresponding `.inp` deck through MAPDL; see `.gitignore`.

| Deck | Used for |
|---|---|
| `ansys_ff_oop_halfsector.inp` | free-free out-of-plane (flexural) FE benchmark, §6 |
| `ansys_ff_oop_ext.inp` | free-free out-of-plane, extended sweep |
| `ansys_ff_oop_mac_extract.inp` | eigenvector export backing the MAC-correlation check (§6.3, see `validation/probe_mac_ambiguity_check.py`) |
| `ansys_ff_ip_ext.inp` | free-free in-plane (extensional) FE benchmark, §6 |
| `ansys_ff_ortho_oop.inp` | orthotropic free-free out-of-plane, Shi/Liang/Wang comparison |
| `ansys_ff_isoval.inp` | isotropic-reduction sanity check of the orthotropic model |
| `ansys_rect_ff_oop_halfmodel.inp` | rectangular free-free out-of-plane (exploratory, corner-term investigation — see main project notes; not part of the validated tables) |
| `ansys_sector_modal.inp` | general annular-sector modal deck |
| `NewAnsys/ansys_ff_isoval_mesh64.inp`, `_mesh80.inp`, `_tagged.inp` | mesh-convergence check (§6.3) for the isoval/tagged model, two mesh densities plus a tagged-node variant |
| `NewAnsys/geomsweep_ip_r200_a100_nu030.txt` | ν=0.30 IP FE table behind §6.6 / Table S.5 (77 elastic modes; job 2410396). Not the same file as `geomsweep/geomsweep_ip_r200_a100.txt` (that is the §6.4 ν=0.35 sweep, 35 modes) |
| `NewAnsys/ansys_ip_r150_a100_nu030_n80.inp`, `_nu035_n80.inp` | raised-NMODES rematch of the §6.5 / Table S.4 IP ceiling (jobs 2421055 / 2421056). Writes `geomsweep_ip_r150_a100_nu030_n80.txt` and `_nu035_n80.txt` (80 modes). Does not replace the published 35-mode lists |
| `NewAnsys/ansys_oop_r200_a50_nu030.inp`, `ansys_ip_r200_a50_nu030.inp` | FE extracts for the crossed-geometry adjudication (jobs 2421900 / 2421901). Writes `geomsweep_oop_r200_a50_nu030.txt` and `geomsweep_ip_r200_a50_nu030.txt` |
| `geomsweep/` | independent FE benchmark for the §6.4 48-geometry generalization sweep, 4 radius ratios × 6 angles × 2 parts — see `geomsweep/README.md` |

Each `.inp` has a matching `*_out.txt` with the extracted text results
(frequencies / mode data), with one exception: `ansys_ff_oop_ext.inp` ships
without its own `_out.txt`. That deck is the same two-pass SHELL281 model
as `ansys_ff_oop_mac_extract.inp` (job 2316746); the Block Lanczos tables
are in `ansys_ff_oop_mac_extract_out.txt`. The in-plane two-mesh lists
extracted from `ansys_ff_ip_ext.inp` are `ip_ext_mesh64.txt` and
`ip_ext_mesh96.txt`.

Where a deck was run on the cluster there is also a `submit_ansys_*.sh`
SLURM wrapper (adapt the SBATCH header, the ANSYS module, and the
hardcoded `cd /home/ghmkfh/PythonMill/Plate_Solver_Package/Ansys/`
line to your own scheduler and install location).
